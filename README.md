# Module 03 — Software Testing Life Cycle (STLC) with AI

This repository contains my **Module 03 assignment** on **Software Testing Life Cycle (STLC) with AI**.

The assignment focuses on creating a complete **Test Plan** and developing validation checklists for an **Online Shopping Website**.

## 📚 PDF Topic Coverage

The assignment PDF covers:

### Q1 — Test Plan for an Online Shopping Website

A complete test plan covering:

- Test Plan Overview
- Test Objective
- Test Scope and Out of Scope
- Test Levels
- Test Types
- Test Approach
- Test Environment
- Test Data
- Entry Criteria
- Exit Criteria
- Defect Management
- Severity and Priority
- Test Deliverables
- Testing Risks
- Roles and Responsibilities
- STLC Testing Schedule
- AI-Assisted Testing Approach
- Approval and Release Readiness

### Q2 — Test Checklists

Three feature-based checklists are included, with **20 validation points for each feature**:

- **Login Checklist — 20 validation points**
- **Registration Checklist — 20 validation points**
- **Checkout Checklist — 20 validation points**

The checklists cover positive, negative, boundary, validation, security, usability, and functional scenarios.

## 🤖 AI-Assisted Testing

AI is used to support the testing process by:

- Generating test ideas and scenarios
- Identifying positive, negative, and boundary cases
- Creating checklist items
- Improving test coverage
- Reviewing potential missing scenarios

All AI-generated suggestions are reviewed and customized by the QA tester based on requirements and testing objectives.

## 🔄 STLC Execution Flow

```text
Requirement Analysis
        ↓
Test Planning
        ↓
Test Case / Checklist Design
        ↓
Test Environment Setup
        ↓
Test Execution
        ↓
Defect Reporting & Retesting
        ↓
Regression Testing
        ↓
Test Closure
```
